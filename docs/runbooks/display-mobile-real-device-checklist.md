# 展示端移动形态真机确认清单

OpenSpec change `mobile-responsive-display` 的 task 7.3（#2818）。规格见 `specs/mobile-regression-evidence` 的「A real-device checklist SHALL close the epic」，口径见该 change `design.md` 的 D15 第 4 点。

本文件只有检查项与空白记录模板，**不含任何结果**。结果由编排者另存为 `docs/runbooks/receipts/` 下的 receipt。

## 目的与范围

自动化合并门与 node-27 实拍（`docs/runbooks/display-mobile-evidence.md`）用的都是 Chromium 设备模拟。模拟器里动态视口高度等于静态高度、安全区恒为 0、没有真实的浏览器工具栏和系统手势，所以下面五类行为只能在真机上确认：

1. 底部控件不被浏览器工具栏遮挡；
2. 控件不进设备安全区（刘海 / 挖孔 / 底部指示条 / 圆角）；
3. 选择器与输入框聚焦时页面不自动放大；
4. 地图与图表里的双指捏合、单指拖动没有手势冲突；
5. 曲线抽屉打开后，选中的河段 / 站点在抽屉旁边仍然看得见。

另外包含 `design.md`「Open Questions」的全部条目（目前一条：全国缩放级别下手指能否点中河段），以及前序 PR 留给真机的携带项。

- **页面范围**：`/`（单图主页：地图、控制条、三个图标按钮、河段曲线窗、气象代站曲线窗）与 `/ops`（内部诊断页，含筛选选择器与作业日志弹窗）。
- **设备范围**：至少一台 iOS Safari、一台 Android Chrome。两台各完整走一遍，每台约 20 分钟。
- **作答方式**：每项填 `通过` / `失败` / `不适用`，加一句备注。写明“竖屏、横屏各做一次”的项，任一方向失败即记 `失败`，备注里写是哪个方向。

## 前置

### 设备与浏览器

- iOS：系统自带 Safari。Android：Chrome。不要用微信等 App 的内置浏览器，不要“添加到主屏幕”后从图标打开，不要开“请求桌面网站”。
- 关闭屏幕方向锁定（清单要在竖屏和横屏之间旋转）。
- 系统字体大小与浏览器页面缩放保持默认（100%）。
- 记下设备型号、系统版本、浏览器版本，填进「结果记录模板」的表头块。

### 入口

- 主图：`https://test.nwm.ac.cn/`
- 已打开气象代站图层的主图：`https://test.nwm.ac.cn/?metStations=1`
- 内部诊断页：`https://test.nwm.ac.cn/ops`（主图上的“运维”扳手按钮只对运维角色显示，公网只读身份看不到，所以直接输入地址）

### 确认拿到的是新构建

1. 用**无痕 / 隐私浏览**标签页打开主图地址（最省事，不带旧缓存）。若用普通标签页，先清站点数据：iOS 在「设置 → Safari 浏览器 → 高级 → 网站数据」里搜 `nwm.ac.cn` 删除；Android 在 Chrome「⋮ → 设置 → 隐私和安全 → 清除浏览数据」里勾选“缓存的图片和文件”。
2. 看页面顶部的蓝色标题栏。**新构建**：一条窄栏（48px 高），小圆形徽标 + 单行标题「全国水文模拟系统（V2.0）」，没有英文副标题。**旧构建**：标题栏明显更高，标题折成两行或下面带一行「NATIONAL WATER MODELING」。
3. 看到旧构建就清缓存后重新打开；仍是旧构建则停止，通知编排者，不要继续做清单。

## 检查项

每一项的“若失败请记录”都至少包含：一张截图（或一段录屏）、设备、方向。下面只写各项额外要记的内容。

### 竖屏主图

#### RD-01 竖屏：控制条不被浏览器工具栏遮挡

- **步骤**：
  1. 手机竖持，打开主图地址，等地图出现。
  2. 看地图底部的控制条：两行是否都完整可见。
  3. 点一下浏览器地址栏再取消（让工具栏展开一次），回到页面再看一次控制条。
  4. 点第二行最右端的时间滑块并拖动一点，再点「下一个」按钮。
- **通过标准**：在你看到的每一种工具栏状态下（刚打开、地址栏展开后、浏览器自动收起工具栏后），控制条两行都完整可见，没有被浏览器底部或顶部工具栏切掉；滑块和按钮都点得到并有反应。
- **若失败请记录**：被遮住的是哪一行 / 哪个控件；当时浏览器工具栏是展开还是收起；iOS 上地址栏设置在顶部还是底部。

#### RD-02 竖屏：标题栏、图标按钮与面板不进安全区

- **步骤**：
  1. 竖屏主图。看标题栏的徽标和文字是否被刘海 / 挖孔 / 状态栏盖住。
  2. 看控制条下边缘与屏幕底部指示条（iOS 的横条 / Android 的手势条）的关系。
  3. 依次点「图层」「底图」「图例」三个图标按钮，各展开一次面板；在「图例」面板里上下滑动。
- **通过标准**：标题栏内容、三个图标按钮、展开的面板、控制条都没有被刘海、圆角或底部指示条遮住或压住；三个面板都完整落在地图范围内，同一时刻只展开一个；从屏幕底边上滑回主屏的系统手势不会误触控制条。
- **若失败请记录**：哪个控件被哪种系统区域遮住。设备没有刘海也没有底部指示条时，本项记 `不适用` 并在备注写明。

#### RD-03 竖屏：控制条两个下拉聚焦不放大

- **步骤**：
  1. 竖屏主图。点控制条的起报时次下拉，在系统弹出的选择器里换一个时次，确认。
  2. 点播放速度下拉，换成 `2x`，确认。
- **通过标准**：点开和选完之后，页面都没有自动放大（标题栏仍与屏幕等宽、页面不能左右拖动）；选中的值正确显示在下拉里。
- **若失败请记录**：是哪个下拉触发了放大；放大后是否需要手动捏回去。起报时次下拉若是灰的（只有「无可用起报时次」），该下拉记 `不适用`，只测播放速度。

### 横屏主图

#### RD-04 横屏：控制条不被浏览器工具栏遮挡

- **步骤**：
  1. 主图打开的状态下把手机横过来，等布局稳定。
  2. 看控制条（此时应是单行）是否完整可见。
  3. 点一下地址栏再取消，回到页面再看；然后拖动时间滑块、点「播放」再点「暂停」。
- **通过标准**：控制条整行可见、可操作，不被浏览器工具栏或标签栏遮挡；标题栏仍是窄栏。
- **若失败请记录**：同 RD-01，另记横屏时浏览器是否自动隐藏了工具栏。

#### RD-05 横屏：左右安全区与标题栏渐变

- **步骤**：
  1. 横屏主图，刘海 / 挖孔在左侧。看标题栏徽标、控制条左端的「GFS / IFS」切换是否被刘海挡住。
  2. 把手机反向横过来（刘海在右侧）。看图标按钮列与控制条右端是否被挡住。
  3. 留意标题栏的蓝色渐变：它在刘海一侧不会铺满到屏幕边缘，会留一条空带。
- **通过标准**：两个横屏方向下，标题栏内容、图标按钮列、控制条都没有被刘海、圆角或底部指示条遮住；刘海一侧标题栏留出的空带在观感上可以接受。
- **若失败请记录**：哪个方向、哪个控件被挡；若只是“空带不好看”，备注里写明是观感问题。设备横屏时左右没有安全区的，记 `不适用`。

#### RD-06 横屏：控制条两个下拉聚焦不放大

- **步骤**：横屏主图，重复 RD-03 的两步（起报时次下拉、播放速度下拉）。
- **通过标准**：同 RD-03；并且选完后控制条仍是完整的一行，没有被系统选择器挤出屏幕后回不来。
- **若失败请记录**：同 RD-03。

#### RD-07 横屏：代站截断提示不盖住控件

- **步骤**：
  1. 横屏打开 `https://test.nwm.ac.cn/?metStations=1`，等地图左上角出现形如「已加载 5000 个代站，列表已截断」的提示。
  2. 看提示与图标按钮列、控制条的位置关系；点一次「图层」按钮再收起，拖一次时间滑块。
  3. 转回竖屏，再看一次。
- **通过标准**：两个方向下提示都没有盖住图标按钮列或控制条的任何控件，三个图标按钮与控制条都点得到；提示最多两行。
- **若失败请记录**：提示盖住了哪个控件；提示的完整文字。提示始终没出现时记 `不适用` 并写明看到的是什么。

#### RD-08 矮屏横屏：无可用周期时滑块不压住禁用原因

- **步骤**：
  1. 仅在小屏手机（如 iPhone SE 第 2 / 3 代）横屏时做。横屏主图，看控制条的起报时次下拉是否显示「无可用起报时次」，且控制条右端有一段黄色的原因文字。
  2. 若出现该状态，看时间滑块是否压在黄色文字上。
- **通过标准**：时间滑块与黄色原因文字不重叠。
- **若失败请记录**：重叠的大致宽度；设备横屏的屏幕尺寸。页面有可用周期（没有黄色文字）或设备不是小屏时，记 `不适用` 并写明原因——这是预期中的大多数情况。

### 曲线窗

#### RD-09 河段曲线窗：选中河段在抽屉旁可见

- **步骤**（竖屏、横屏各做一次）：
  1. 主图，双指放大到某个流域，直到河段线清楚可辨。记住你要点的那一段的位置特征（例如某个交汇口旁边）。
  2. 轻触这段河。
  3. 等抽屉弹出、地图自己平移停下。
- **通过标准**：抽屉弹出（竖屏在底部，横屏在右侧），里面出现曲线；你点的那段河（通常以白底橙线高亮）落在**没有被抽屉盖住**的那部分地图里，大致居中，没有被抽屉压住，也没有贴到屏幕边缘；地图没有变更缩放级别；控制条与图标按钮列在抽屉打开期间完全消失。
- **若失败请记录**：选中河段最后停在哪里（被抽屉盖住 / 贴边 / 出了屏幕）；抽屉在哪一侧；控制条或图标按钮是否还露着。

#### RD-10 气象代站曲线窗：选中站点在抽屉旁可见，两种窗互相替换

- **步骤**（竖屏、横屏各做一次）：
  1. 打开气象代站图层（见「界面叫法」下的说明），放大到出现单个代站圆点。
  2. 轻触一个圆点，等抽屉弹出、地图平移停下。
  3. 不关抽屉，在露出的地图上轻触一段河。
- **通过标准**：第 2 步后气象代站曲线窗出现并有曲线，被点的站点落在未被抽屉盖住的地图区内、大致居中；第 3 步后抽屉内容换成河段曲线窗（同一时刻只有一个窗），地图再平移一次，把那段河移到未遮盖区。
- **若失败请记录**：是站点不可见，还是两个窗同时存在，还是换窗后没有平移。露出的地图里点不到河段时，第 3 步记 `不适用`。

#### RD-11 抽屉内的选择器与按钮：不放大、弹层不进安全区

- **步骤**（竖屏、横屏各做一次）：
  1. 打开河段曲线窗。点「起报」后面的时次选择器，在弹出的列表里选另一个时次。
  2. 关闭，打开气象代站曲线窗。同样点一次时次选择器；再依次点五个要素切换按钮。
  3. 点抽屉右上角 ✕。
- **通过标准**：点选择器时页面不自动放大；弹出的时次列表完整落在屏幕可见范围内，不被刘海、底部指示条或浏览器工具栏遮住，每一项都点得到；五个要素按钮和 ✕ 都一次点中，没有被系统区域挡住。
- **若失败请记录**：哪个控件；弹层被哪条边切掉。抽屉里没有「起报」选择器（该要素没有可选时次）时，选择器部分记 `不适用`。

#### RD-12 抽屉开着旋转屏幕

- **步骤**：
  1. 竖屏打开河段曲线窗，等曲线出现后**立刻**把手机转到横屏。
  2. 观察 3 秒，再转回竖屏。
  3. 换成气象代站曲线窗，重复第 1、2 步。
- **通过标准**：每次旋转后——抽屉换到新的一侧（竖屏底部 / 横屏右侧）；图表画布跟到新尺寸，没有停在旧尺寸、被拉伸或留白；控制条与图标按钮列仍然隐藏；选中的河段 / 站点重新落在未被抽屉盖住的地图区内、大致居中，没有偏到屏幕边缘或被抽屉盖住。
- **若失败请记录**：是哪一条不成立（图表尺寸 / 外壳露出 / 选中要素位置）；从哪个方向转到哪个方向；最好录屏。iOS Safari 上这一项尤其要做。

#### RD-13 关闭抽屉后控制条恢复原状、不续播

- **步骤**：
  1. 竖屏主图，记下时间滑块当前的位置。点「播放」，让它走两三步。
  2. 播放中轻触一段河，打开河段曲线窗（点不中就先暂停再点，然后重新播放、再点）。记下抽屉弹出那一刻滑块走到的位置。
  3. 点 ✕ 关闭抽屉。
- **通过标准**：抽屉打开期间控制条与图标按钮列完全不可见；关闭后二者重新出现，预报源、起报时次与打开前一致，时间滑块停在抽屉弹出那一刻的位置，**没有继续播放**（播放按钮显示为“播放”而不是“暂停”）；三个面板都是收起的。
- **若失败请记录**：关闭后是否在自动播放；滑块是否跳到了别的时刻。

#### RD-14 抽屉主体没有多余的滚动

- **步骤**（竖屏、横屏各做一次）：
  1. 打开河段曲线窗，确认图表已完整显示在抽屉里。
  2. 在抽屉内图表以外的位置（标题下方的「起报」那一行）用一根手指上下滑动。
- **通过标准**：图表能完整显示时，抽屉内容不发生上下位移或回弹；页面整体也不跟着滚动。
- **若失败请记录**：位移大概多少（一丝 / 明显）；是抽屉内部在滚还是整个页面在动。

#### RD-15 地图版权标注不妨碍抽屉内的阅读与点击

- **步骤**（竖屏、横屏各做一次；河段曲线窗与气象代站曲线窗各看一眼）：
  1. 打开曲线窗，找地图的版权标注：竖屏时它在图表右下角附近，横屏时在图表区右侧。
  2. 看它是否盖住了曲线、坐标轴刻度或文字。
  3. 在它所在的位置及紧邻处，点一次图表（应出现数值提示），再点一次离它最近的按钮。
- **通过标准**：版权标注没有盖住需要读的曲线或刻度到影响判读的程度；它没有拦住对图表、要素按钮、时次选择器或 ✕ 的点击（点下去起作用的是抽屉里的控件，而不是标注）。
- **若失败请记录**：盖住了什么；点击被拦截时，点的是哪个控件、实际发生了什么（例如标注展开了）。看不到版权标注时记 `通过` 并备注“未见标注”。

#### RD-16 平移动画进行中关闭抽屉

- **步骤**：竖屏主图，轻触一段河；抽屉刚弹出、地图还在滑动时（约半秒内）立刻点 ✕。
- **通过标准**：抽屉关闭，地图把那次平移滑完后停下；没有卡顿、抖动、来回弹，控制条与图标按钮列正常恢复。手感可以接受。
- **若失败请记录**：出现了什么（抖动 / 卡死 / 外壳没恢复）；若只是“滑完这一下感觉别扭”，备注里写明是手感问题。

#### RD-17 手动拖动地图后不被拉回

- **步骤**：
  1. 竖屏打开河段曲线窗，等地图平移停下。
  2. 在露出的地图上用一根手指把地图拖到别处，松手，等 3 秒。
  3. 在露出的地图上轻触另一段河。
  4. 再拖动一次地图，然后把手机转到横屏。
- **通过标准**：第 2 步后地图停在你拖到的位置，**不**被拉回选中河段；第 3 步后地图平移一次，把新选中的河段移到未遮盖区；第 4 步旋转后地图再平移一次，把选中河段移到横屏的未遮盖区。
- **若失败请记录**：哪一步不符合；若你认为“拖动之后旋转不应该再平移”，记 `失败` 并在备注写明这是对规则本身的意见（这条规则的优先级此前未经确认）。

### 手势

#### RD-18 地图上的双指捏合与单指拖动

- **步骤**（竖屏、横屏各做一次）：
  1. 主图，无抽屉。在地图上双指捏合放大、再缩小。
  2. 单指向四个方向各拖一次；其中一次从屏幕左边缘内侧一点开始向右拖，一次从地图上部向下拖。
- **通过标准**：捏合只缩放地图，页面整体（标题栏、控制条）不跟着放大；单指拖动只平移地图，不触发浏览器的后退 / 前进、下拉刷新，也不把页面整体拖动；地图缩放按钮（＋／－）在手机上不显示属正常。
- **若失败请记录**：触发了哪种浏览器或系统手势；是否每次都能复现。

#### RD-19 河段图表里的双指缩放与单指拖动

- **步骤**（竖屏、横屏各做一次）：
  1. 打开河段曲线窗。在图表上双指张开。
  2. 在图表上单指左右拖动。
  3. 单指按住图表上一点停一下。
- **通过标准**：双指张开只放大图表的时间轴（曲线变宽、时间刻度变疏）；单指左右拖动平移时间轴；按住的位置出现数值提示。整个过程中抽屉后面的地图不动，页面不整体缩放，抽屉不被拖走，也不触发浏览器后退。
- **若失败请记录**：实际是谁在响应手势（地图 / 整个页面 / 浏览器 / 没反应）。

#### RD-20 气象代站图表里的双指缩放与单指拖动

- **步骤**（竖屏、横屏各做一次）：打开气象代站曲线窗，在图表上重复 RD-19 的三步；再切换一个要素按钮后重复一次双指张开。
- **通过标准**：同 RD-19；切换要素后手势仍然有效。
- **若失败请记录**：同 RD-19，另记是哪个要素。

#### RD-21 播放中轻触河段的命中率

- **步骤**：
  1. 竖屏主图，放大到河段线清楚可辨，播放速度选 `2x`。
  2. 点「播放」，播放过程中轻触一段河。记下抽屉是否弹出。
  3. 关闭抽屉（没弹出就点「暂停」），重新点「播放」，再轻触。共做 5 次。
- **通过标准**：5 次里至少 4 次弹出抽屉。
- **若失败请记录**：实际命中次数（例如 `2/5`）；暂停状态下点同一段河是否每次都能点中（用来区分是“播放时点空”还是“这段河本身难点”）。无论通过与否，都在备注写 `命中 n/5`。

### `/ops`

前置：在地址栏输入 `https://test.nwm.ac.cn/ops`。页面标题应为「内部诊断」，并有一段以 `display_readonly：` 开头的只读说明。若显示「权限不足」，本组四项全部记 `不适用` 并备注，不算失败。

#### RD-22 `/ops`：页面可滚到底，底部内容不被遮挡

- **步骤**（竖屏、横屏各做一次）：
  1. 在页面内容上单指上滑，一直滑到最底部。
  2. 滑到作业表格时，在表格上左右滑动。
- **通过标准**：页面内容是单列；能滑到最后一块内容且它完整可见，不被浏览器工具栏或底部指示条盖住；作业表格在自己的框内左右滚动，页面整体不左右晃动；内容左右没有贴到刘海或屏幕圆角里。
- **若失败请记录**：滑不到的是哪一块；是否出现整页横向滚动。

#### RD-23 `/ops`：选择器与时间输入框聚焦不放大

- **步骤**（竖屏做一次；横屏只做第 1 步）：
  1. 点「SOURCE」下面的选择器，选任意一项。
  2. 点「CYCLE TIME (UTC)」下面的时间输入框，弹出系统时间选择器后直接取消（不要改时间）。
  3. 滑到作业表格上方，依次点「全部状态」「全部类型」「全部场景」三个筛选选择器，各自打开后选回原项或点外面关闭。
- **通过标准**：点任何一个时页面都不自动放大；选择器的弹出列表完整落在屏幕可见范围内，不被刘海、底部指示条或浏览器工具栏遮住，每一项都点得到。
- **若失败请记录**：是哪个控件触发了放大，或哪个弹层被切掉。

#### RD-24 `/ops`：作业日志弹窗

- **步骤**（竖屏、横屏各做一次）：
  1. 在作业表格里把某一行向左滑到最右一列，点「查看日志」。
  2. 弹窗出现后，在黑色日志区里上下、左右滑动。
  3. 点弹窗右上角的 ✕ 关闭。
- **通过标准**：弹窗四条边都在屏幕可见范围内，不被刘海、底部指示条或浏览器工具栏遮住；标题「作业日志 …」可读；日志区可以上下和左右滚动；✕ 看得见、一次点中。日志内容显示「加载失败: …」不算本项失败（本项只看弹窗的位置与可操作性）。
- **若失败请记录**：弹窗哪条边出了屏幕或被遮住；✕ 是否点得到。作业表格没有任何一行或没有「查看日志」按钮时记 `不适用`。

#### RD-25 `/ops`：底部弹出提示不进安全区

- **步骤**（竖屏、横屏各做一次）：滑回页面顶部的概要区，点「刷新」按钮，看屏幕底部（宽屏时靠右下角）弹出的提示（成功时为「监控数据已刷新」）。
- **通过标准**：提示完整可见，文字与它的关闭按钮没有被底部指示条、屏幕圆角、刘海或浏览器工具栏遮住。
- **若失败请记录**：提示被哪种系统区域遮住；提示的文字。「刷新」按钮是灰的或点了没有任何提示时记 `不适用`。

### 开放问题

#### RD-26 全国缩放级别下手指能否点中河段

- **步骤**（竖屏做；横屏可选）：
  1. 新开主图地址，**不要缩放**，保持打开时的全国视野。
  2. 挑 5 段看得见的河段线，逐一轻触；每次若抽屉弹出就关闭它再点下一段。记下弹出了几次。
  3. 双指放大到某个流域，再轻触 5 段河，记下弹出了几次。

## 失败项处置

- 每个 `失败` 都由编排者立一个后续 issue，编号填进结果表的「后续 issue」列，并在 receipt 里引用。失败项**不豁免**、不改写成 `不适用`。
- `不适用` 必须在备注里写明原因（设备没有该系统区域、页面未出现该状态等）。两类设备都 `不适用` 的检查项，由编排者在 receipt 里单列说明。
- 只在一类设备上失败也算失败；issue 里写明是哪一类设备、哪个方向。
- epic 只在每个检查项在两类设备上都有记录之后才关闭。
- 真机上暴露的 iOS / Android 差异是否需要代码改动、是否另立后续 change，等本清单结果出来后由编排者与用户决定（`design.md`「Not yet specified」），本清单不预设处置。

## 不在本清单范围

| 事项 | 原因 |
|---|---|
| `/monitoring` | 需要运维角色，公网只读身份进不去；它与 `/ops` 是同一个页面组件的另一种模式，移动样式相同，由 `/ops` 的四项代表 |
| `/system/model-assets` | 需要模型管理角色；本 change 对它只保证“不撑破页面”，由自动化合并门覆盖 |
| 曲线窗开着时从桌面形态缩到移动形态（#2811 携带项的后半句） | 手机在竖屏和横屏下都是移动形态，无法在手机上产生这次形态切换；由 mocked 回归在 Chromium 里覆盖。旋转触发的那一半在 RD-12 |
| 开发用角色切换器 | 只存在于开启角色覆盖的开发构建，公网构建里没有 |
| 平板（768×1024 竖屏等桌面形态） | 属桌面形态，由桌面 project 的自动化断言覆盖 |
| 宽 320px 及更窄的设备 | 规格只钉到 390px 宽；更窄的情形在前序 task 中列为范围外观察 |
| 控件尺寸（44px）、字号（16px）、图表最小高度等数值 | 由自动化合并门与 node-27 实拍的几何 JSON 证明，真机上不重复量 |
| 抽屉的进出场动画、下拉关闭手势、双击复位缩放 | 本 change 未实现，不是检查对象 |
| 数据本身是否正确（曲线数值、起报时次是否最新） | 与移动形态无关，由展示端既有的 live receipt 覆盖 |
