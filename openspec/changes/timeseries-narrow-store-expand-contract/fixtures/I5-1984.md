No surface sniffs a process environment for store. Detection is catalog-only.

1. Pre-expand (production today): no `hydro.hydro_run.timeseries_store` column, no `hydro.river_timeseries_legacy`. Canonical `hydro.river_timeseries` is the current text-shaped table. Every surface MUST keep today's table names, column sets, SQL, plan lines and error codes byte-identical.
2. Post-expand (I7 catalog, disposable tests only): column exists with `legacy`|`narrow`; canonical table is narrow-shaped; `_legacy` exists and is text-shaped.
3. Mid-expand / only-legacy: `_legacy` exists and canonical is missing. Publisher schema preflight MUST accept this window (either name satisfies). Copyback/QHH/plan nails fail closed or follow the per-surface rule below — they do not invent a store.
