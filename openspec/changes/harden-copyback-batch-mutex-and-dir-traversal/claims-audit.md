# Claims audit (#2035)

Registered corrective action of the Review Failure Retro at PR #2201 round 3
(`shape: depth`). The retro named this recurring invariant:

> A claim about this change — that a behaviour is covered by a test, or that the
> code does what a spec / design / task / runbook / code-comment sentence says —
> is true only if it was re-derived from the artifact **after the last change to
> the area it describes**.

The E19 lane × behaviour matrix in `tasks.md` is the mechanism for the coverage
half of that rule. This file is the mechanism for the prose half: every sentence
of this change that asserts a behaviour gets one row, and every row records the
**falsifier that was constructed and checked** — the concrete input, ordering,
uid/gid, filesystem state, exception or interleaving that would make the sentence
false — not a confirmation that the happy path works. A row whose falsifier is
"none" is not a checked row.

Scope (bounded deliberately; rationale prose asserts no behaviour and is out):

- every WHEN / THEN / AND clause of both spec deltas, plus this branch's changed
  lines in `openspec/changes/display-v2-national-timeline-precip-overlay/specs/canonical-precip-copyback/spec.md`
- every behaviour assertion in `design.md`, `tasks.md`, `proposal.md`
- every operator-visible claim (message text, default value, recovery step) in
  `infra/env/README.md`, `docs/runbooks/current-production-ops.md` §5.3,
  `docs/runbooks/forcing-copyback-backfill.md`
- every behaviour comment this branch added to `packages/common/copyback_guard.py`
  and `services/orchestrator/run_tree_copyback.py`

Audited at head `b59ffd2e` by two independent read-only passes. 85 rows:
**1 FALSE, 8 UNPROVEN, 76 HOLDS** at audit time. Adjudicating those rows against
production then moved three more: six UNPROVEN resolved to HOLDS, one (A27)
resolved to **FALSE**, one (B46) to a recorded over-narrow instruction, and one

fact was known. Final: **3 FALSE (all fixed in this head), 1 over-narrow (fixed), 2 HOLDS whose
stated truth-maker named the wrong layer (corrected in place, outcome unaffected),
79 clean HOLDS.** The two extra FALSEs were found by the fix pass reading the code the
audit row named — which is the point of recording the truth-maker per row.
